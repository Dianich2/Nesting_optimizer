# Этап21: поворот и отмена до ручной постановки

База: чистый `1d405973c77f892a4bca888d8aa1eef51d055a1c`, `wip/geometry-editor-v2`. Начат после PASS gate20; при найденном общей регрессией дефекте отмены SQL дополнительно вернулись к этапу20, доказали и исправили его, повторили матрицу. Рабочие данные и .env не менялись; браузер/API/PostGIS работают на отдельной `nesting_test`. Никаких commit/push/merge.

## Причина и решение

До изменения `add(x,y)` отправлял rotation0, ghost делал только translate. Исправлены `NestingPage.tsx`, `NestingCanvas.tsx`, добавлены `placementDraft.ts` и локальные стили. Угол до постановки хранится как raw string с последним валидным числом; конечные значения нормализуются modulo360. Есть0/90/180/270, произвольный угол, R+90/Shift+R−90. Ghost и POST используют один угол, центр исходного bbox → rotate → перенос в(X,Y); осьY соответствует серверу. Не добавлены округления/epsilon в production geometry.

Esc существовал и раньше; утверждение «Esc не работал вообще» неверно. Теперь SVG фокусируемый, получает фокус при pointerdown; подсказки и отмена рядом с названием выбранного лекала над холстом. Горячие клавиши не перехватывают поля ввода/select/contenteditable, модальное окно, Ctrl/Meta/Alt; R блокируется при unsafe pending/busy. Локальная отмена не делает HTTP и доступна без ожидания сервера. Повтор той же детали выключает режим, другая деталь сбрасывает угол0. Переход на другую поверхность размонтирует draft. После409 сохраняются ghost и угол; success выбирает сохранённую деталь и открывает свойства. На узком экране свойства являются существующим overlay; закрываются кнопкой «Панель» перед дальнейшим взаимодействием с холстом.

Запись блокируется при текущем mutation, refreshRequired, proposal, pending save/preview и неподтверждённом outcome. Обработчик add повторно проверяет условия и finite raw angle. Undo/redo серверных операций и геометрическая валидация сохранены.

## Ограничения и ручная приёмка

Нужна проверка удобства R/Esc/локальной панели на физической клавиатуре и touch-устройстве. Chromium touch emulation не является испытанием iOS/Safari. Нельзя отменой draft отменить уже отправленную и подтверждённую сервером запись: для неё работает Undo. Исходный проект пользовательницы отсутствует, геометрию её узкого места следует проверить вручную. Git HEAD сохранён; итоговый status/diff/check и общий test gate находятся в сводке.
